# Evaluacion2

Proyecto de la Evaluación Parcial N° 2 de Telepresencia y Entornos Innovadores de Colaboración Humana (CUY6142).

## Descripción

Script en Python de geolocalización que calcula una ruta en auto entre dos lugares. El programa pide el origen y el destino, obtiene sus coordenadas y luego muestra la distancia total, el tiempo estimado y las instrucciones paso a paso. Los textos están en español y los valores numéricos se muestran con dos decimales. Para terminar el programa se escribe "s" o "salir".

## Requisitos

- Python 3
- Librería `requests` (`pip install requests`)
- Conexión a internet

## Cómo ejecutar

1. Descargar el archivo `geolocalizacion.py`.
2. Ejecutar en la terminal:

   `python3 geolocalizacion.py`

3. Ingresar el origen y el destino cuando el programa lo pida.
4. Escribir "s" o "salir" para cerrar el programa.
